# 单词学习 H5 技术设计文档

## 1. 文档说明

### 1.1 目的

本文档是"单词学习 H5"项目的技术设计文档，面向开发与联调人员。文档基于 [proposal.md](./proposal.md) 的需求，描述系统的**数据库设计、后端 API 设计、前端页面与组件设计**，以及核心业务逻辑的实现方案。

### 1.2 范围

- 数据库：复用现有 `book` / `words` 表，新增 `User` 表（明确化）、`learning_progress` 表。
- 后端：Next.js Route Handlers（业务 API）+ NextAuth v5（认证 API）。
- 前端：移动端 H5 页面（首页、我的、学习页、详情页）与组件。

### 1.3 名词约定

| 名词 | 说明 |
|---|---|
| `book` 表 | 单词书表（元数据） |
| `words` 表 | 单词数据表（每词一行） |
| `User` 表 | H5 用户表（邮箱 + 密码，项目名沿用现有 `"User"`） |
| `learning_progress` 表 | 用户学习进度表（断点续学依据） |
| `wordRank` | 单词在书中的序号（1 ~ N），学习进度以它为单位 |

## 3. 数据库设计

### 3.1 现有表（复用，不改结构）

#### `book` 单词书表

```sql
create table public.book (
  id uuid not null default gen_random_uuid (),
  title character varying(255) not null,
  word_count integer not null default 0,
  cover_url text null,
  book_id text not null,
  tags text null,
  created_at timestamp with time zone not null default now(),
  updated_at timestamp with time zone not null default now(),
  constraint book_pkey primary key (id),
  constraint book_book_id_unique unique (book_id)
) TABLESPACE pg_default;
```

| 字段 | 类型 | 说明 |
|---|---|---|
| id | uuid | 主键 |
| title | varchar(255) | 书名，如"PEP小学英语三年级上" |
| word_count | integer | 单词总数（与 words 表实际行数保持一致） |
| cover_url | text | 封面图地址 |
| book_id | text | 业务标识（唯一），如 `PEPXiaoXue3_1`，与 words.bookId 关联 |
| tags | text | 逗号分隔标签，如"小学,人教版,三年级" |
| created_at / updated_at | timestamptz | 创建/更新时间 |

#### `words` 单词数据表

```sql
create table public.words (
  id bigint generated by default as identity not null,
  "wordRank" integer null,
  "headWord" text null,
  content json null,
  "bookId" text null,
  constraint words_pkey primary key (id)
) TABLESPACE pg_default;
```

| 字段 | 类型 | 说明 |
|---|---|---|
| id | bigint | 主键（identity） |
| wordRank | integer | 词序号（1 ~ N），**学习顺序与进度依据** |
| headWord | text | 单词，如 `ruler` |
| content | json | 单词完整数据（`word.content` 结构，见 5.2） |
| bookId | text | 所属单词书（对应 book.book_id） |

注意：`words` 表列名带引号（`"wordRank"`、`"headWord"`、`"bookId"`），大小写敏感，Drizzle 定义与查询时必须严格匹配。

### 3.2 新增表

#### `User` 用户表（明确化，与现有 db.ts 动态建表一致）

现有 [db.ts](file:///c:/Users/26066/Desktop/workspace/danci/nextjs-typescript-starter/app/db.ts) 会在运行时自动创建该表。正式迁移脚本如下（表名带引号，大小写敏感）：

```sql
create table public."User" (
  id serial not null,
  email varchar(64) null,
  password varchar(64) null,
  constraint User_pkey primary key (id)
) TABLESPACE pg_default;
```

| 字段 | 类型 | 说明 |
|---|---|---|
| id | serial | 主键 |
| email | varchar(64) | 邮箱（登录账号） |
| password | varchar(64) | bcrypt 哈希（60 字符，varchar(64) 足够） |

#### `learning_progress` 学习进度表（新增）

```sql
create table public.learning_progress (
  id bigint generated by default as identity not null,
  user_id integer not null,
  book_id text not null,
  last_word_rank integer not null default 0,
  updated_at timestamp with time zone not null default now(),
  constraint learning_progress_pkey primary key (id),
  constraint learning_progress_user_book_unique unique (user_id, book_id),
  constraint learning_progress_user_id_fkey
    foreign key (user_id) references public."User"(id) on delete cascade,
  constraint learning_progress_book_id_fkey
    foreign key (book_id) references public.book(book_id) on delete cascade
) TABLESPACE pg_default;

create index learning_progress_user_idx on public.learning_progress (user_id);
```

| 字段 | 类型 | 说明 |
|---|---|---|
| id | bigint | 主键（identity） |
| user_id | integer | 用户（FK → User.id） |
| book_id | text | 单词书（FK → book.book_id） |
| last_word_rank | integer | 最近学到的词序号（已学到的位置，0 表示未开始） |
| updated_at | timestamptz | 最近学习时间（首页"最近学习"按此排序取最新） |

设计要点：
- `unique (user_id, book_id)`：一用户一书一行，进度采用 **upsert**。
- `on delete cascade`：删除用户/单词书时自动清理进度。
- 派生指标不落库：`learnedCount = last_word_rank`，`progress% = last_word_rank / book.word_count`。
- 学习模型为**顺序学习**（last_word_rank 单调递增），不做单词级明细记录（MVP 简化，见"待确认"）。

#### 4.2.2 session 中暴露 userId

NextAuth JWT 默认把用户主键放在 `token.sub`，而 `session.user` 不含 id。需要在 `auth.ts` 中补充 session callback，供进度接口使用：

```ts
callbacks: {
  async session({ session, token }) {
    if (session.user) session.user.id = token.sub ?? '';
    return session;
  },
},
```

使用处统一 `Number(session.user.id)` 转换为 DB 的 serial 类型。

#### 4.2.3 页面访问控制（修改 auth.config.ts）

原逻辑把所有已登录用户重定向到 `/protected`，H5 不再需要。改为仅保护 `/learn` 与 `/word`：

```ts
callbacks: {
  authorized({ auth, request: { nextUrl } }) {
    const isLoggedIn = !!auth?.user;
    const isLearningRoute =
      nextUrl.pathname.startsWith('/learn') ||
      nextUrl.pathname.startsWith('/word');
    if (isLearningRoute && !isLoggedIn) {
      return Response.redirect(new URL('/', nextUrl));
    }
    return true; // 首页、我的对所有人开放
  },
},
```

#### 4.2.4 注册接口 `POST /api/auth/register`

登录弹窗需要在客户端完成注册，提供独立注册接口（不依赖现有 `/register` 页面）：

```ts
// app/api/auth/register/route.ts
export async function POST(request: Request) {
  const body = await request.json().catch(() => null);
  const email = typeof body?.email === 'string' ? body.email.trim() : '';
  const password = typeof body?.password === 'string' ? body.password : '';

  if (!email || !/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(email)) {
    return NextResponse.json({ error: '请输入正确的邮箱' }, { status: 400 });
  }
  if (!password || password.length < 6) {
    return NextResponse.json({ error: '密码至少 6 位' }, { status: 400 });
  }

  const exists = await getUser(email);
  if (exists.length > 0) {
    return NextResponse.json({ error: '该邮箱已注册' }, { status: 409 });
  }

  await createUser(email, password); // bcrypt 加密落库
  return NextResponse.json({ ok: true }, { status: 201 });
}
```

前端注册成功后调用 NextAuth `signIn('credentials')` 自动登录（见 5.5）。

```ts
    .where(eq(words.bookId, bookId))

```

```ts
// app/lib/progress.ts
export async function getProgress(userId: number, bookId: string) {
  const rows = await db.select().from(learningProgress)
    .where(and(eq(learningProgress.userId, userId), eq(learningProgress.bookId, bookId)))
    .limit(1);
  return rows[0] ?? null;
}

export async function listProgress(userId: number) {
  // 关联 book 表取书名/封面，按最近学习时间倒序
  return db.select({
      bookId: learningProgress.bookId,
      lastWordRank: learningProgress.lastWordRank,
      updatedAt: learningProgress.updatedAt,
      title: books.title,
      wordCount: books.wordCount,
      coverUrl: books.coverUrl,
    })
    .from(learningProgress)
    .innerJoin(books, eq(books.bookId, learningProgress.bookId))
    .where(eq(learningProgress.userId, userId))
    .orderBy(desc(learningProgress.updatedAt));
}

export async function upsertProgress(userId: number, bookId: string, lastWordRank: number) {
  return db.insert(learningProgress)
    .values({ userId, bookId, lastWordRank })
    .onConflictDoUpdate({
      target: [learningProgress.userId, learningProgress.bookId],
      set: { lastWordRank, updatedAt: new Date() },
    });
}

export async function resetProgress(userId: number, bookId: string) {
  return db.delete(learningProgress)
    .where(and(eq(learningProgress.userId, userId), eq(learningProgress.bookId, bookId)));
}
```

### 4.4 API 接口设计

#### 4.4.1 通用规范

- 请求/响应：`application/json`。
- 成功：HTTP 2xx，直接返回业务数据（如 `{ books: [] }`、`{ ok: true }`）。
- 失败：HTTP 4xx/5xx，返回 `{ "error": "错误描述" }`。
- 认证：登录态接口用服务端 `auth()` 取会话，未登录返回 `401 { error: '未登录' }`。
- 数据库访问统一走 Drizzle 参数化查询，不使用字符串拼接 SQL。

#### 4.4.2 接口明细

| 接口 | 方法 | 认证 | 说明 |
|---|---|---|---|
| `/api/books` | GET | 公开 | 单词书列表（按创建时间倒序） |
| `/api/books/[bookId]/words` | GET | 公开 | 某本书全部单词（按 wordRank 升序） |
| `/api/auth/register` | POST | 公开 | 注册（查重 + 创建） |
| `/api/progress` | GET | 登录 | 当前用户全部学习进度（关联书名） |
| `/api/progress` | POST | 登录 | 保存/更新单本书进度（upsert） |
| `/api/progress/[bookId]` | GET | 登录 | 单本书进度 |
| `/api/progress/[bookId]` | DELETE | 登录 | 重置该书进度（重新学习） |

登录/登出：复用 NextAuth 的 `/api/auth/signin`、`/api/auth/signout` 与 `signIn`/`signOut` 客户端 API，不额外实现。

### 4.5 核心业务逻辑

#### 学习起点计算

```
输入：progress（可能为 null）、book.wordCount
若 progress 为 null：startRank = 1
否则：
  startRank = progress.lastWordRank + 1
  若 startRank > wordCount：标记"本书已学完"，提供"从头重新学习"（DELETE /api/progress/[bookId] 后 startRank = 1）
```

学习页 `index = startRank - 1`（0 基数组下标）。

#### 进度保存

- 触发时机：用户点击【下一个】时，将**当前卡片**的 `wordRank` 作为 `lastWordRank` 提交（表示该词已学）。
- 提交策略：仅当 `wordRank > 本地已保存的 lastWordRank` 时提交，避免重复请求；失败静默重试一次，不阻塞翻卡。
- 用户中途退出：进度已保存，下次进入从 `lastWordRank + 1` 继续。

#### 学完判定

- 当前卡片为最后一词（`index === words.length - 1`）时，点击【下一个】提示"本书已学完"，并提供"重新学习"（重置进度）。

### 5.5 登录/注册弹窗（LoginDialog，客户端组件）

方案：**API 注册 + NextAuth 客户端 signIn + router.refresh()**。

```tsx
// 登录
const res = await signIn('credentials', { email, password, redirect: false });
if (res?.error) { setError('邮箱或密码错误'); return; }
router.refresh();           // 刷新 Server Components 登录态
router.push('/');           // 或跳回目标学习页

// 注册
const r = await fetch('/api/auth/register', {
  method: 'POST',
  body: JSON.stringify({ email, password }),
});
if (!r.ok) { setError((await r.json()).error); return; }
// 注册成功后自动登录
const res = await signIn('credentials', { email, password, redirect: false });
router.refresh();
```

弹窗内部模式切换：登录 / 注册（字段相同，文案与提交逻辑不同）。

### 5.6 单词学习页 `/learn/[bookId]`

### 5.7 单词详情页 `/word/[bookId]/[wordRank]`

Server Component 按 `bookId + wordRank` 定位单词，渲染 `content.word.content` 全部区块：

### 5.8 发音播放（app/lib/audio.ts）

`ukspeech` / `usspeech` 存的是相对参数（`type=1` 英式、`type=2` 美式），需拼固定 base：

```ts
const AUDIO_BASE = 'https://dict.youdao.com/dictvoice'; // 联调确认

export function audioUrl(word: string, type: 1 | 2): string {
  return `${AUDIO_BASE}?audio=${encodeURIComponent(word)}&type=${type}`;
}

export function playAudio(src: string) {
  new Audio(src).play();
}
```

解析方式：从 `ukspeech`/`usspeech` 中提取 `type` 参数，如 `ruler&type=1` → `audioUrl('ruler', 1)`。

## 7. 安全设计

| 项 | 方案 |
|---|---|
| 密码存储 | bcrypt（`bcrypt-ts`），不存明文 |
| 会话 | NextAuth JWT + `AUTH_SECRET` 签名 |
| 接口鉴权 | 进度接口统一 `auth()` 校验，未登录 401 |
| 注册校验 | 邮箱格式 + 密码长度 + 邮箱查重 |
| SQL 注入 | 全部走 Drizzle 参数化查询 |
| 越权防护 | 所有进度操作仅基于当前 session 用户 id，不接受客户端传 userId |
| 输入校验 | 接口入口对 body 字段做类型与长度校验 |

## 10. 风险与待确认

1. 发音音频 base URL（`dict.youdao.com/dictvoice`）需联调确认可用性与跨域。
2. `session.user.id` 依赖 NextAuth token.sub，需确认 Credentials 登录后 token.sub 为 User.id。
3. 登录成功后跳转目标：当前设计为记录"待学习 bookId"，登录后直接进入该书学习页。
4. 进度模型为顺序学习（last_word_rank 单调递增），若需支持跳词/复习需扩展明细表。
5. `book.word_count` 与 `words` 实际行数可能出现不一致，学习页以 `words.length` 为准，进度展示以 `book.word_count` 为准（或统一用 words 统计）。
