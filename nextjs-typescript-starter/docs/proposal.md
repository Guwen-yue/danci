# 单词学习 H5 项目需求文档

## 1. 项目概述

### 1.1 产品定位

面向小学阶段英语学习者的 **移动端 H5 单词学习应用**（手机浏览器访问，按移动端布局设计）。提供"单词书 → 单词卡片学习 → 单词详情"的完整学习闭环，并记录用户的个人学习进度，支持断点续学。

### 1.2 项目目标

1. 用户可浏览所有单词书，并进入单词学习。
2. 未登录用户可浏览单词书；点击单词书后引导登录，登录后才能记录学习进度。
3. 已登录用户可从"最近学习"的断点继续学习（从最近学到的单词的**下一个**开始）。
4. 单词卡片保持简洁（仅展示一个示例），完整内容通过点击单词进入详情页查看。
5. "我的"页面展示用户邮箱、学习进度，支持退出登录。

### 1.3 技术选型（基于现有工程）

| 项目 | 选型 |
|---|---|
| 框架 | Next.js（App Router）+ TypeScript |
| 样式 | Tailwind CSS |
| 认证 | NextAuth v5（Credentials Provider） |
| 数据库 | PostgreSQL（Postgres.js + Drizzle ORM） |
| 单词数据源 | danci-admin 后台维护的 `book` / `words` 表（数据源自 `danci-admin/temp/*.json`） |

## 2. 页面结构与路由

| 路由 | 页面 | 底部 Tab | 说明 |
|---|---|---|---|
| `/` | 首页 | 显示 | 单词书列表 +（登录后）最近学习模块 |

## 3. 功能需求

### 3.1 全局底部导航栏

- 固定在页面底部，仅"首页"和"我的"两个 Tab。
- 首页 Tab 默认激活；切换时高亮对应 Tab 图标与文字。
- `/learn` 与 `/word` 页面**隐藏**底部导航，提供顶部返回按钮，营造沉浸式学习体验。

```
┌──────────────────────────────┐
│          页面内容             │
│                              │
│                              │
├──────────────────────────────┤
│  ● 首页            ○ 我的    │
└──────────────────────────────┘
```

### 3.2 首页 `/`

**3.2.1 已登录状态（有最近学习记录）**

自上而下展示：

1. 【最近学习】模块（横向卡片）：
   - 展示最近学习的单词书标题、标签、学习进度（已学 X / 总词数 Y）。
   - 点击后进入该单词书学习页，**从最近学到的单词的下一个开始**。
2. 【全部单词书】列表：
   - 展示所有单词书（`book` 表），每项含封面、标题、标签、词数。
   - 点击后进入该单词书学习页（从第 1 个单词开始，若该书无进度记录）。

**3.2.2 已登录状态（无最近学习记录）**

- 不展示【最近学习】模块，仅展示【全部单词书】列表。

**3.2.3 未登录状态**

- 不展示【最近学习】模块，仅展示【全部单词书】列表。
- 点击任意单词书：切换到【我的】Tab，并弹出登录弹窗（见 3.3）。
- 登录成功后：自动进入刚才点击的单词书学习页（建议，见"待确认问题"）。

### 3.3 登录 / 注册弹窗

- 以 Popup（Modal）形式在【我的】页面弹出，支持两种模式切换：**登录** / **注册**。
- 表单字段：邮箱、密码。
- 交互逻辑：
  - 登录模式：调用 `signIn('credentials', { email, password, redirectTo: '/' })`，校验失败提示"邮箱或密码错误"。
  - 注册模式：先 `getUser(email)` 查重，已存在则提示"该邮箱已注册"；否则 `createUser(email, password)`，创建成功后自动登录。
  - 切换链接："没有账号？去注册" / "已有账号？去登录"。
- 参考现有逻辑：登录参考 `app/login/page.tsx`，注册参考 `app/register/page.tsx`。

### 3.4 我的 `/me`

- **未登录**：展示"去登录"按钮，点击弹出登录弹窗（3.3）。
- **已登录**：
  1. 用户信息区：显示用户邮箱。
  2. 学习进度区：按单词书展示进度条（已学 X / 总词数 Y，百分比），并提供总体统计（累计已学单词数 / 全部单词总数）。
  3. 退出登录按钮：调用 `signOut({ redirectTo: '/' })`，退出后回到首页。

### 3.5 单词学习页 `/learn/[bookId]`

**学习起点规则（断点续学核心逻辑）：**

1. 读取 `learning_progress` 表中该用户的 `lastWordRank`。
2. 无记录（首次学习）→ 从 `wordRank = 1` 开始。
3. 有记录 → 从 `wordRank = lastWordRank + 1` 开始（即最近学到的下一个单词）。
4. 若 `lastWordRank >= 该书总词数` → 提示"本书已学完"，提供"从头重新学习"。

**页面 UI：**

- 顶部：返回按钮 + 书名。
- 中间：单词卡片（一次一张），内容保持简洁：
  - `headWord`（单词）
  - `usphone`（美式音标）
  - `trans[0].tranCn`（中文释义）
  - `sentence.sentences[0]`（**第一条**例句：英文 + 中文）
- 点击卡片任意位置 / 单词 → 跳转单词详情页 `/word/[bookId]/[wordRank]`。
- 底部：进度提示（如 `3 / 120`）+【下一个】按钮。
  - 点击【下一个】：保存当前已学进度（`lastWordRank` = 当前卡片 `wordRank`），切换到下一张卡片。
  - 已到最后一词：显示"本书已学完"完成态。

**进度保存时机：** 点击【下一个】时调用 `POST /api/progress` 更新 `lastWordRank`；用户中途退出，下次进入从保存的位置继续。

### 3.6 单词详情页 `/word/[bookId]/[wordRank]`

渲染 `content.word.content` 完整字段（数据结构见第 5、7 章），自上而下：

| 区块 | 渲染字段 |
|---|---|
| 头部 | `wordHead`（单词）+ 英/美发音按钮（`uk speech` / `usspeech`）+ 英/美音标 |
| 释义 | `trans[]`：中文释义（tranCn）+ 英文释义（tranOther） |
| 例句 | `sentence.sentences[]`：全部例句（英文 + 中文） |
| 同近词 | `syno.synos[]`：词性 + 中文释义 + 同近词列表 |
| 同根词 | `relWord.rels[]`：按词性分组，展示派生词及释义 |
| 记忆方法 | `remMethod.val` |

## 4. 数据模型

### 4.1 现有表（直接复用）

**`book` 单词书表**（danci-admin 维护）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | uuid | 主键 |
| title | varchar | 书名，如"PEP小学英语三年级上" |
| wordCount | integer | 单词总数 |
| coverUrl | text | 封面图 |
| bookId | text | 业务标识，如 `PEPXiaoXue3_1`，与 words 表关联 |
| tags | text | 逗号分隔标签，如"小学,人教版,三年级" |

**`words` 单词表**（每词一行，`content` 存完整 JSON）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | bigint | 主键 |
| wordRank | integer | 词序号（1 ~ N，学习顺序与进度依据） |
| headWord | text | 单词，如 `ruler` |
| content | json | 单词完整数据（详见第 5 章结构） |
| bookId | text | 所属单词书 |

**`User` 用户表**（nextjs-typescript-starter 现有）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | serial | 主键 |
| email | varchar(64) | 邮箱 |
| password | varchar(64) | bcrypt 加密密码 |

### 4.2 新增表 `learning_progress`（学习进度）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | serial | 主键 |
| userId | integer FK → User.id | 用户 |
| bookId | text | 单词书 |
| lastWordRank | integer | 最近学到的词序号（已学到的位置） |
| updatedAt | timestamp | 最近更新时间 |

- 唯一约束 `(userId, bookId)`：一用户一书一行。
- 派生字段（无需落库）：`learnedCount = lastWordRank`，`totalCount = book.wordCount`，进度百分比 = `lastWordRank / wordCount`。

## 6. 接口设计

| 接口 | 方法 | 说明 |
|---|---|---|
| `GET /api/books` | GET | 单词书列表（供首页"全部单词书"） |
| `GET /api/books/[bookId]/words` | GET | 某本书全部单词（按 `wordRank` 升序） |
| `GET /api/progress` | GET | 当前用户全部学习进度（供首页"最近学习"、"我的"页） |
| `GET /api/progress/[bookId]` | GET | 某本书的进度（供学习页计算起点） |
| `POST /api/progress` | POST | 保存 / 更新进度（`{ bookId, lastWordRank }`，upsert） |
| 登录 / 注册 / 退出 | - | 复用 NextAuth 现有逻辑（`signIn` / `signOut` + `createUser`） |

注：以上接口均为登录态接口（`auth()` 校验），未登录返回 401。

## 7. 字段与页面渲染映射表

| 字段路径 | 含义 | 学习卡片 | 详情页 |
|---|---|---|---|
| `headWord` | 单词 | 展示 | 展示 |
| `wordRank` | 词序号（1~N） | 进度依据、路由参数 | - |
| `content.word.content.ukphone` | 英式音标 | - | 展示 |
| `content.word.content.usphone` | 美式音标 | 展示 | 展示 |
| `content.word.content.uk speech` | 英式发音（`type=1`） | - | 播放按钮 |
| `content.word.content.usspeech` | 美式发音（`type=2`） | - | 播放按钮 |
| `content.word.content.trans[0].tranCn` | 中文释义 | 展示 | 展示 |
| `content.word.content.trans[0].tranOther` | 英文释义 | - | 展示 |
| `content.word.content.sentence.sentences` | 例句（英/中） | 仅第 1 条 | 全部 |
| `content.word.content.syno.synos` | 同近词（词性/释义/近义词） | - | 展示 |
| `content.word.content.relWord.rels` | 同根词（按词性分组） | - | 展示 |
| `content.word.content.remMethod.val` | 记忆方法 | - | 展示 |

**发音地址拼接：** `usspeech` / `ukspeech` 存的是 `ruler&type=2` / `ruler&type=1` 相对参数（`type=1` 英式、`type=2` 美式）。音频地址由固定 base 拼接而成（联调时确认 base，如 `https://dict.youdao.com/dictvoice?audio={headWord}&type={1|2}`）。

## 9. 关键交互流程

### 9.1 首页 → 学习（未登录）

```
点击单词书 → 切换到【我的】Tab → 弹出登录弹窗
   → 登录成功 → 返回首页 → 进入该单词书学习页（从第 1 词开始）
   → 登录失败 → 弹窗内提示错误，停留在弹窗
```

### 9.2 首页 → 学习（已登录）

```
点击【最近学习】→ /learn/[bookId]，起点 = lastWordRank + 1
点击单词书     → /learn/[bookId]，起点 = 1（该书无进度）或 lastWordRank + 1
```

### 9.3 学习页进度保存

```
进入 /learn/[bookId]
  → GET /api/progress/[bookId] 读取 lastWordRank
  → 展示卡片（wordRank = lastWordRank + 1）
点击【下一个】
  → POST /api/progress { bookId, lastWordRank: 当前词 }
  → 展示下一张卡片
```

### 9.4 我的 → 退出登录

```
点击【退出登录】→ signOut() → 重定向到首页 → 首页变为未登录态
```

## 10. 非功能需求

1. **移动端适配**：以 375px 设计稿为基准，自适应常见手机屏幕宽度；底部导航适配 iPhone 安全区（`env(safe-area-inset-bottom)`）。
2. **性能**：单本单词书词量约 100~200，`/learn` 页一次性加载该书全部单词（按 wordRank 排序）并做前端索引；数据量大时可改为按序分页加载。
3. **音频播放**：使用 HTML5 `Audio` 播放拼接后的发音地址。
4. **无 emoji**：项目 UI 与文案不使用 emoji 表情（遵循项目规范）。
5. **文案语言**：界面文案使用中文，单词学习内容保持英文原文。
